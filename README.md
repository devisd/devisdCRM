# Devis Studio — учёт заказов

Локальное приложение для одного пользователя: клиенты, заказы, позиции работ, оплаты и история сотрудничества. Техническое задание — в [`SPEC.md`](./SPEC.md).

## Возможности MVP

- Обзор: активные заказы, оплаты за месяц, ожидаемые суммы, ближайшие сроки
- Клиенты: создание, редактирование, карточка, поиск, архив (без потери истории)
- Заказы: несколько позиций, скидка, статусы, сроки, фильтры и поиск
- Оплаты: частичные платежи, остаток и статус оплаты (без ручного статуса)
- Резервные копии JSON: экспорт / строгий импорт с полной заменой базы
- Интерфейс на русском, адаптив desktop / tablet / mobile

Не входит: сервер, облако, аккаунты, PWA, интеграции, налоги, вложения.

## Стек

- Next.js 16 (App Router), React 19, TypeScript strict
- SCSS Modules
- Dexie.js + IndexedDB
- Zod, date-fns, Lucide React, Vitest

Денежные суммы хранятся **целыми числами в копейках**, в интерфейсе показываются в рублях.

## Запуск

В Cursor удобно использовать **Git Bash** (терминал по умолчанию можно выбрать в настройках). В папке проекта:

```bash
npm install
npm run dev
```

Откройте в браузере: [http://localhost:3000](http://localhost:3000).

Остановка сервера: `Ctrl+C`.

Production:

```bash
npm run build
npm run start
```

Если команда `npm` не находится, установите [Node.js LTS](https://nodejs.org/) и перезапустите терминал. PowerShell тоже подходит — команды те же.

## Локальное хранение данных

- Все пользовательские данные живут **только в IndexedDB** текущего браузера/профиля.
- Данные **не отправляются** на сервер и не синхронизируются между устройствами.
- Очистка данных сайта, другой браузер, другой профиль или потеря устройства = риск потери базы.
- Физическое удаление клиента с заказами запрещено — используйте архив.

## Резервное копирование

Раздел **Настройки**:

1. **Экспорт JSON** — файл вида `devis-studio-backup-YYYY-MM-DD.json`
2. **Импорт JSON** — полная замена текущей базы после проверки формата, связей и сумм
3. При ошибке валидации импорт **отклоняется**, текущие данные не меняются
4. **Тестовые данные** и **очистка базы** — только по явному действию с подтверждением

Рекомендуется экспортировать копию перед импортом, очисткой и важными правками.

## Офлайн (ограничения)

Проверено по архитектуре MVP (без PWA / Service Worker):

| Сценарий | Ожидание |
|----------|----------|
| Приложение уже открыто, сеть пропала | CRUD в IndexedDB продолжает работать |
| Повторное открытие URL без сети | Зависит от HTTP-кэша браузера для JS/CSS; гарантии нет |
| Первый заход без сети | Невозможно: файлы приложения нужно загрузить |

Для сохранности данных опирайтесь на **регулярный экспорт JSON**, а не на офлайн-кэш браузера.

## Структура

```text
src/
  app/                 # маршруты App Router
  components/          # UI, клиенты, заказы, обзор, настройки
  lib/
    db/                # Dexie
    repositories/      # доступ к данным
    services/          # деньги, статусы, бэкап, статистика
    validation/        # Zod
    format/            # рубли и даты
  types/
```
